# Jhonatan Montaño

Desarrollador de software enfocado en **fintech y medios de pago**. Construyo aplicaciones financieras de extremo a extremo: apps móviles, backend en la nube e integraciones con pasarelas y redes de pago.

## En qué trabajo

- **Pagos e integraciones bancarias** — PSE (PlaceToPay y Avanza / MOVII), Bre-B / Pagos Inmediatos, conciliación de transacciones y manejo de webhooks.
- **Productos financieros** — ahorro, créditos y CDAT: cálculo de intereses, retenciones y flujos de firma y desembolso.
- **Onboarding y seguridad** — registro con validación de identidad (KYC), firma electrónica, autenticación biométrica y OTP.
- **Notificaciones en tiempo real** — push (FCM) para estados de pago, crédito y cuenta.

## Stack

**Móvil:** Flutter · Dart
**Backend:** Node.js · TypeScript · Cloud Functions
**Nube:** Google Cloud (Cloud Run · Cloud SQL) · Firebase (Firestore · Auth · FCM)
**Web:** React · Next.js
**Otros:** Python · REST · integración con APIs bancarias
